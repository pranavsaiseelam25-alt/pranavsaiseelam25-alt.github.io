SAGE

Active development

Self-Adaptive General Intelligence Engine · Independent project · Windows desktop

A personal AI assistant that works as a single intelligent interface between you and your computer. SAGE shouldn't just explain how to do a task. It's being built to understand what you want, plan it, carry out authorized actions, and verify the result. It's an ambitious engineering project, not artificial general intelligence.

  • Python
  • FastAPI
  • React
  • TypeScript
  • pywebview
  • WebView2
  • Ollama
  • Qwen 2.5 3B
  • SQLite
  • nomic-embed-text

Where it stands

  • Phase 1, the Skills Engine, is implemented and undergoing live verification
  • Working skills include natural-language routing, system diagnostics, volume control, and opening apps, files and approved websites
  • Actions need confirmation first, and they're audited and verified
  • Engineering work has improved routing reliability, stopped fabricated action-success messages, and kept file discovery inside approved directories
  • Latest development report: 303 automated tests passed and 28 skipped, including 40 new tests
  • Live verification of the latest fixes is a separate step and is still pending

What's next

  • Phase 1: finish stabilizing the Skills Engine
  • Phase 2: voice, with a local wake phrase, speech recognition and spoken responses
  • Phase 3: practical skills such as PDFs, contacts and reminders
  • Phase 4: diagrams, schematics and data visualization
  • Phase 5: real web search and citation-backed reports
  • Phase 6: agentic work, running multi-step tasks across apps and verifying the results
  • Phase 7: consent-based location sharing and mobile integration
  • Also planned: Companion Mode, an optional warm and supportive conversational style

Engineering principles

Local-first, modular and transparent, with authorization required for consequential actions. It's designed for consumer-grade hardware and uses free, open-source tools with no paid API dependencies.

Runs locally for now, so there's no public link yet

VIVEKA

Early development

Adaptive multilingual English learning · Educational technology · Entrepreneurship

VIVEKA began with my Sanskrit teacher, Vivek, who wanted to become good at English but wasn't sure how to go about it. The app is named after him. Many people are in the same position: motivated, but without a structured path explained in a language they already understand. VIVEKA is being built to teach English through Indian regional languages, with Chinese as an additional language, and to adapt to what each learner already knows.

Language should not be a barrier to learning another language.

Objective

Making English education adaptive to the learner, rather than expecting every learner to adapt to the same curriculum.

  • Python
  • FastAPI
  • SQLAlchemy
  • SQLite

Where it stands

  • Core objectives, proposed architecture and adaptive-learning approach are established
  • Project structure, development environment and backend stack are in place
  • Initial design of the multilingual language-support framework is done
  • Learner profiles, curriculum management and assessments are being planned
  • Foundational backend components are in development

What's next

  • A modular backend and the multilingual framework
  • Learner profiles that separate native, instruction and target languages
  • A curriculum from foundational to advanced, covering reading, writing, listening, speaking, grammar and vocabulary
  • Diagnostic assessments and an adaptive learning engine
  • An AI tutor that explains errors in the learner's preferred language
  • A learner-friendly frontend, then testing of educational effectiveness, language accuracy and accessibility

Not yet a finished or publicly deployed product

NeuroCube

Research framework in development

Cubing · Rehabilitation research · Leadership

I started NeuroCube to help people with cubing, something I know well and like. We're exploring how Rubik's Cube-based activities relate to cognitive-motor coordination, and whether they could be useful in neurological rehabilitation research. Areas of interest include focal hand dystonia, stroke rehabilitation, multiple sclerosis and dementia-related challenges.

Where it stands

  • About 50 people work on NeuroCube
  • As founder and chief project director, I manage the team and lead negotiations
  • Pursuing collaborations with experts and established organizations such as Ignite Youth Community (IYC)
  • The research framework is still developing

What's next

  • Literature reviews and specific, defensible research questions
  • Relationships with academics and healthcare professionals
  • An ethical framework and supervised research

NeuroCube's proposed activities are not clinically validated treatments.
